# AetherX

A full-stack microblogging platform built with **FastAPI**.

AetherX provides a clean JSON API and a responsive HTML frontend for creating, reading, updating, and managing blog posts with user authentication and profile images.

AetherX has:
- A JSON REST API for programmatic access
- An simple HTML frontend with Jinja2 templates for basic UI access

---

## Features

- User registration & login (JWT)
- Create, read, update, delete posts
- User profiles
- Image uploads (profile pictures / post images)
- Pagination
- Password reset with background email tasks
- Async SQLAlchemy + Alembic migrations
- PostgreSQL support
- Testing with Pytest
- Deployment (VPS + Docker)

---

## Tech Stack

- **FastAPI**
- **SQLAlchemy** (async)
- **Pydantic** v2
- **Jinja2** + static files
- **JWT** authentication
- **Alembic**
- **PostgreSQL** / SQLite
- **Uvicorn**
- **Pytest**
